# Fundamentals of Programming (Fundamentos da Programação)

Introductory programming course at Instituto Superior Técnico, taught in Python.

Covers algorithms, procedural and data abstraction, and programming paradigms. Topics include:
control structures, functions and procedural abstraction, recursion (linear and tree recursion),
higher-order and functional programming, strings, lists, tuples, dictionaries, file I/O, and
introductory object-oriented programming (classes, subclasses, inheritance, polymorphism), as
well as basic data structures (stacks, queues).
